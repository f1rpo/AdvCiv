- Renaming

	- "Play Now" → "Simple Game" Clearer, matches code name, better contrasts with "Custom Game", and same as in C2C mod.
	- Foreign Advisor's "Active" tab -> "Treaties" tab (no longer shows redundant bonuses).

- AI
	- Do not buy dominated or equivalent strategic bonuses (era and bonus-aware): strategic resource buying now uses explicit exclusion rules, so AI skips dominated/equivalent offers instead of considering them as valid buys. Examples: in Classical, Copper is not needed if we have Iron; in Classical metals and mounted lines can substitute each other so redundant buys are skipped; Horse and Camel are treated as equivalent in Classical/Medieval/Renaissance; in Industrial (before Modern), Horse has the edge (no Camel Dragoon), so Camel is skipped if Horse is already available, etc. Change in CvPlayerAI::AI_bonusTrade. See KI#109.
	- Workers: prefer farms on low-food BFCs
	- Workers: also remove incorrect food production checks in worker logic: regardless of if we produce a settler or not, what matters is long term food situation.
	- Workers: account for farms being built as future food difference for city. Aims to fix multiple simultaneous farms followed by multiple simultaenous workshops edge case for a high pop but somehow unimproved city
	- Tribute/counter-propose consistency fix for pure Vassal/Surrender offers: base AdvCiv/BtS diplomacy would reject direct Tribute/Demand ("Not bloody likely"), yet clicking "What do you want in exchange?" would accept for the same demand (with nothing extra). So players had to do an unnecessary extra click to get the same vassal result. Fixed by making CvPlayerAI::AI_considerOffer accept this exact pure one-item vassal/surrender demand directly, and by making CvDiplomacy.py not remember this narrow accepted case as a tribute demand memory (because this is rather a UI consistency fix). See KI#108.
	- Unit scrapping: now gated strictly by domain/era: (e.g., an archer is not useful at medieval era, but a knight unit is still useful at industrial era). These are raw XML-cost gates (no game-speed scaling). Also added a naval exception: sea units carrying cargo are never scrapped (e.g., a galley is still useful to transport units).
	- City evacuation — doomed city: now tunable via SAS defines (default ON, recommended). Addresses player feedback at: https://forums.civfanatics.com/threads/advciv-sas-simple-advanced-strategy.699716/post-16921308
	- Minimum Stack size before war: Added a minimum stack unit count requirement to prevent the stack from being marked as "ready" until it has enough units: no MOVE_DECLARE_WAR flag, no premature advance toward the city, and AI keeps building units until the stack is big enough. Helps fix the issue of "back and forth" war declarations with immediate retreat without city attack: low-numbered unit stacks were especially sensible to power swings (city defenses, one more enemy units skews win chance, etc.). Change in CvUnitAI::AI_attackCityMove. See KI#104.
	- Fix leaders inconsistently not having 150 as the total of their BBAI victory weights: (iCultureVictoryWeight, iSpaceVictoryWeight, iConquestVictoryWeight, iDominationVictoryWeight, iDiplomacyVictoryWeight, 150): (LEADER_BISMARCK, 20, 25, 25, 30, 40, 140) -> 20, 25, 25, 35, 45, 150; (LEADER_BRENNUS, 0, 30, 30, 50, 30, 140) -> 0, 30, 35, 55, 30, 140; (LEADER_LINCOLN, 10, 35, 35, 15, 45, 140) -> 10, 40, 35, 15, 50, 150; (LEADER_RAMESSES, 25, 25, 35, 35, 20, 140) -> 35, 25, 35, 35, 20, 150.
	- Better support Earth2' heaviness computation: Earth2 now treated as Land type. Fine tuned logic and made map heaviness now tunable in SAS defines. Addresses issue of Earth2 having AI being too weak when it treated it incorrectly as a naval heavy map, as per player feedback at https://forums.civfanatics.com/threads/advciv-sas-simple-advanced-strategy.699716/post-16916283. Reviewed other mapscripts similarly so they are better assessed as landheavy or navalheavy, and added fallback logic to determine type based on the number of players per area.

Music is also playable via Sevopedia Music/Media Player. Change in CvMainMenuInfo::getSoundtrack in CvInfo_Misc.cpp.
